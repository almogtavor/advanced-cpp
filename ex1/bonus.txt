Bonus features implemented:

1. Logging system
   - File: include/util/Logger.h
   - A singleton Logger class that writes timestamped, level-filtered log
     messages (DEBUG, INFO, WARNING, ERROR) to a log file (drone_mapper.log)
     created in the same directory as the input/output files.
   - Used in: src/main.cpp (lines 30-80), src/Simulator.cpp (lines 32-40, 67-75, 82)
   - The log level is set to DEBUG by default and can be changed programmatically.
   - LOG_DEBUG / LOG_INFO / LOG_WARNING / LOG_ERROR convenience macros are provided.
   - Log file is automatically created on each run; no additional configuration
     needed. Logs include: startup info, config loading status, grid dimensions,
     drone start position, collision warnings, safety cap warnings, and final score.
